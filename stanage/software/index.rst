Software on Stanage
===================

These pages provide a list software available on the Stanage cluster. If you notice an error or
an omission, or wish to request new software submit a request to
`research-it@sheffield.ac.uk <mailto:research-it@sheffield.ac.uk?subject=HPC Software installation request>`_ .
 
These sections cover commonly used packages in more detail, including documentation on their interactive
and batch usage with examples where applicable. The aim is to help users get started and make efficient use of the software on Stanage.
